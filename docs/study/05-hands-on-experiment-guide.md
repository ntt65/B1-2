# 05. 직접 뜯어보며 배우는 실습 가이드 (Hands-on Lab)

> **목표**: 리액트를 몰라도 겁먹지 않고, **코드를 딱 한 줄씩 고쳐보며 화면이 어떻게 바뀌는지 체감**한다.

---

## 1. 개발 서버 띄우기

터미널에서 아래 명령어를 실행하면 내 컴퓨터에 웹사이트가 켜집니다:

```bash
npm install   # 필요한 패키지 설치 (처음 1번만)
npm run dev   # 개발용 서버 실행
```

브라우저에서 `http://localhost:5173`으로 접속하면 우리가 만든 아이템 매니저 웹사이트가 뜹니다!

---

## 2. 실험 1: 화면의 글자 바꿔보기 (컴포넌트 체감)

- **파일**: `src/components/Layout.jsx`
- **위치**: 11번째 줄 근처
- **원래 코드**:
  ```jsx
  <Link to="/items" ...>📝 Item Manager</Link>
  ```
- **이렇게 바꿔보세요**:
  ```jsx
  <Link to="/items" ...>🚀 나의 첫 번째 멋진 리액트 앱</Link>
  ```
- **결과 확인**: 파일을 저장(Ctrl+S / Cmd+S)하자마자 브라우저 새로고침을 안 눌러도 상단 제목이 즉시 바뀝니다! 이것이 리액트의 **HMR(Hot Module Replacement)**입니다.

---

## 3. 실험 2: 버튼 색깔 바꿔보기 (인라인 스타일 체감)

- **파일**: `src/components/ItemCard.jsx`
- **위치**: "삭제" 버튼 부분
- **원래 코드**:
  ```jsx
  <button onClick={() => onDelete(item.id)} style={{ ..., color: '#dc2626' }}>삭제</button>
  ```
- **이렇게 바꿔보세요**:
  ```jsx
  <button onClick={() => onDelete(item.id)} style={{ ..., color: '#2563eb', background: '#dbeafe' }}>지우기</button>
  ```
- **결과 확인**: 모든 아이템 카드의 삭제 버튼이 파란색으로 한 번에 바뀝니다. 부품(컴포넌트) 하나를 고치면 이 부품을 쓰는 모든 곳에 자동 적용됩니다!

---

## 4. 실험 3: 고의로 에러 내보기 (에러 배너 체감)

- **파일**: `src/hooks/useItems.js`
- **내용**: `fetchItems` 함수 안에서 강제로 에러를 던져보세요:
  ```javascript
  throw new Error("내가 만든 실험용 가짜 에러입니다!");
  ```
- **결과 확인**: 화면이 하얗게 뻗지 않고, 빨간색 `<ErrorBanner>` 컴포넌트가 뜨면서 "내가 만든 실험용 가짜 에러입니다!"라는 메시지가 정돈되어 나타납니다.

---

## 5. 문제가 생겼을 때 디버깅하는 방법 (F12 개발자 도구)

1. 키보드의 **F12** (맥은 Cmd+Option+I)를 누릅니다.
2. **[Console]** 탭을 누르면 자바스크립트 에러나 `console.log` 기록이 빨간 글씨로 뜹니다.
3. 코드 중간중간에 `console.log("여기 실행됨! 데이터는:", data)`를 적어두면 데이터가 어떻게 흘러가는지 눈으로 확인할 수 있습니다.
