# 01. 리액트(React) 핵심 멘탈 모델 — 리액트를 전혀 모르는 입문자 가이드

> **대상**: HTML/JS 기초는 알거나 들어봤지만, "리액트가 도대체 뭐고 왜 쓰는지" 전혀 모르는 학습자  
> **목표**: 리액트 코드를 읽기 전에 머릿속에 '리액트가 돌아가는 기본 원리' 그림을 그릴 수 있게 만든다.

---

## 1. 리액트가 도대체 뭔가요?

우리가 평소에 쓰는 네이버, 구글 검색창을 생각해보세요.
- **옛날 웹사이트**: 링크를 누르면 화면 전체가 하얗게 깜빡이면서 새로운 HTML 파일을 서버에서 처음부터 다시 받아옵니다. (새로고침)
- **요즘 웹사이트 (SPA, Single Page Application)**: 유튜브에서 다른 영상을 누르거나, 인스타그램에서 피드를 내려도 **화면 전체가 새로고침되지 않고 필요한 부분만 스르륵** 바뀝니다.

**리액트(React)**는 바로 이런 "버튼을 누르면 화면 전체를 새로고침하지 않고, 바뀌어야 할 일부분만 마법처럼 갈아 끼워주는 도구"입니다.

---

## 2. 리액트의 3대 핵심 개념 (레고 블록 비유)

리액트를 이해하려면 딱 3가지 단어만 알면 됩니다: **컴포넌트(Component)**, **State(상태)**, **Props(속성)**.

```
+-------------------------------------------------------+
|  Layout (전체 틀)                                     |
|  +-------------------------------------------------+  |
|  | Header (상단 로고 & 메뉴 블록)                  |  |
|  +-------------------------------------------------+  |
|  +-------------------------------------------------+  |
|  | Main Content (상황에 따라 갈아 끼워지는 블록)   |  |
|  |                                                 |  |
|  |   [ItemCard] [ItemCard] [ItemCard]              |  |
|  +-------------------------------------------------+  |
|  +-------------------------------------------------+  |
|  | Footer (하단 안내 블록)                         |  |
|  +-------------------------------------------------+  |
+-------------------------------------------------------+
```

### ① 컴포넌트 (Component) = "레고 블록"
- 웹 화면을 통째로 하나로 만들면 코드가 너무 길어져서 관리할 수 없습니다.
- 그래서 화면을 버튼, 카드, 헤더, 목록처럼 **작은 부품(레고 블록) 단위로 쪼개어 함수로 만든 것**을 **컴포넌트**라고 부릅니다.
- 예: `ItemCard.jsx`는 아이템 한 칸을 보여주는 작은 레고 블록이고, `ItemListPage.jsx`는 그 카드 블록들을 모아놓은 큰 판입니다.

### ② State (상태) = "컴포넌트의 기억 상자"
- 컴포넌트가 기억하고 있어야 하는 **현재 값**입니다.
- 예: "지금 장바구니에 담긴 물건 개수: 3개", "지금 선택된 카테고리: 전체"
- **리액트의 가장 큰 특징**: **State(기억)의 값이 바뀌면, 리액트가 알아서 화면을 자동으로 다시 그려줍니다.** (우리가 직접 `document.getElementById`로 글자를 안 바꿔도 됨!)

### ③ Props (속성) = "부모 블록이 자식 블록에게 건네주는 전달품"
- 레고 블록끼리 데이터를 주고받을 때 사용합니다.
- 부모 컴포넌트가 자식 컴포넌트를 부를 때 값을 넘겨줍니다.
- 예: `ItemListPage`(부모)가 `ItemCard`(자식)에게 "너는 1번 글(제목: 사과)을 보여줘!"라고 데이터를 건네줄 때, 그 전달품을 **Props**라고 합니다.

## 3. JSX란 뭔가요? (HTML인 듯 HTML 아닌 자바스크립트)

리액트 파일 확장자가 `.js`가 아니라 `.jsx`인 이유가 있습니다.

자바스크립트 코드 안에서 HTML 태그 모양(`<div>`, `<h1>`, `<button>`)을 그대로 쓸 수 있게 만든 문법이 바로 **JSX**입니다.

```jsx
// 일반 자바스크립트 함수인데, HTML 태그를 반환(return)합니다!
function WelcomeButton() {
  const name = "철수"; // 자바스크립트 변수

  // 중괄호 { } 를 쓰면 자바스크립트 변수나 연산 결과를 HTML 안에 쏙 집어넣을 수 있습니다.
  return (
    <button className="my-btn">
      안녕하세요, {name}님!
    </button>
  );
}
```

## 4. 화면이 부드럽게 바뀌는 원리 (Virtual DOM)

1. 사용자가 "삭제" 버튼을 누릅니다.
2. 컴포넌트의 **State(아이템 목록)**에서 해당 아이템이 빠집니다.
3. 리액트가 속으로 생각합니다:
   > *"어? State가 바뀌었네? 이전 화면이랑 비교해보니 2번째 카드 하나만 사라졌군!"*
4. 브라우저 전체를 새로고침하는 대신, **화면에서 딱 그 2번째 카드만 쏙 지워버립니다.**

이것이 리액트가 빠르고 화면이 스르륵 바뀌는 근본적인 이유입니다.
